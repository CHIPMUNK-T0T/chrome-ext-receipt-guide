# ECサイト領収書ナビゲーター

ECサイト領収書ナビゲーターは、日本のECサイトで領収書を取得するときに、注文履歴ページや領収書関連の操作箇所まで迷わず進めるように補助するChrome拡張機能です。

Amazon.co.jp、楽天市場、Yahoo!ショッピングなど、日本国内でよく利用されるECサイトを対象に、領収書取得までの導線を分かりやすく案内します。

## この拡張機能でできること

- 対象ECサイトの注文履歴ページをすぐに開く
- ECサイト上に領収書取得のための案内を表示する
- 「領収書」「領収書等」「注文詳細」などの関連リンクやボタンを見つけやすくする
- ダウンロードしたPDFの保存名整理を補助する
- サイト別・年月別に領収書PDFを整理しやすくする

## 対象サイト

初期対応予定のサイトは以下です。

- Amazon.co.jp
- 楽天市場
- Yahoo!ショッピング

## 使い方

1. Chrome拡張機能をインストールします。
2. Chromeのツールバーから「ECサイト領収書ナビゲーター」を開きます。
3. 領収書を取得したいECサイトを選択します。
4. 対象サイトの注文履歴ページが開きます。
5. 画面上の案内に従って、領収書または購入明細のページへ進みます。
6. 必要に応じて、領収書PDFを保存します。

## この拡張機能の方針

この拡張機能は、領収書の完全自動取得ツールではありません。

ユーザー自身が各ECサイト上で行う領収書取得作業を補助するためのナビゲーションツールです。

そのため、以下のような操作は行いません。

- 自動ログイン
- IDやパスワードの保存
- 注文履歴の自動収集
- 領収書の一括自動ダウンロード
- CAPTCHAの回避
- 購入履歴や領収書データの外部送信

## プライバシーについて

ECサイト領収書ナビゲーターは、ログイン情報、購入履歴、領収書PDFの内容を外部サーバーへ送信しません。

設定情報は、Chromeブラウザ内に保存されます。

この拡張機能が使用する権限は、注文履歴ページへの移動、対象ページ上での案内表示、ダウンロードファイル名の整理など、機能提供に必要な範囲に限定します。

## 注意事項

- 領収書の発行可否、表示内容、取得方法は各ECサイトの仕様に依存します。
- ECサイト側の画面変更により、案内やハイライトが正しく表示されない場合があります。
- 本拡張機能は、各ECサイトが公式に提供する領収書発行機能の利用を補助するものであり、各ECサイトの公式サービスではありません。
- 領収書の内容や税務上の扱いについては、必要に応じて専門家へ確認してください。

## 開発目的

ECサイトの領収書取得は、個人事業主、フリーランス、副業ユーザー、経費精算を行う会社員にとって、毎回少し面倒な作業です。

この拡張機能は、日本の主要ECサイトで領収書を取得するときの迷いを減らし、確定申告や経費精算の準備を少し楽にすることを目的としています。
